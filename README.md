# Python Practice Exercises

A collection of Python exercises solved while practicing core language concepts — basic syntax, data types, control flow (`if`, `while`, `for`, `match`), and data structures (lists, tuples, dictionaries, sets).

Each file contains a set of hand-picked exercises with working, tested solutions and their expected output.

## Contents

| File | Topics Covered |
|---|---|
| [`python-level2-selected-exercises.md`](./python-level2-selected-exercises.md) | Nested loops, dictionaries, prime number checking, string processing, nested data structures |

## Topics Practiced

- Variables & basic data types
- Numbers & operators
- Strings, lists, tuples, dictionaries, sets
- Conditional statements (`if` / `elif` / `else`, `match`)
- Loops (`for`, `while`), including nested loops
- Common algorithmic patterns (finding max/min without built-ins, counting, accumulating sums/averages)

## How to Run

Each code block is a self-contained Python script. Copy the code into a `.py` file and run it with:

```bash
python filename.py
```

Requires Python 3.10+ (for `match` statement support).
